# Setup window

The crew arrives 90 minutes before the first course for a seated dinner, and 60 minutes before a drop-off.

Do not offer an earlier arrival unless the client is paying the staffing overtime position. If they ask "what time do you get there," answer with the window above. Do not ask them to pick a time we already set.
